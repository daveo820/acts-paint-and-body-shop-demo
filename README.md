# Act's Paint & Body Shop: concept demo

Hand coded static concept site by LuminArch for Act's Paint & Body Shop (Durham, NC). Not an official site. `noindex`, robots Disallow.

- Live: https://acts-paint-and-body-shop-demo.vercel.app/
- Build: `python3 build.py` writes the HTML pages. No framework, no build step on Vercel.
- Docs: `market-research.md`, `FACTS_LOG.md`, `DESIGN_DNA.md`. Competitor screenshots in `research/`.
- Photos in `img/` are the shop's own, from its former website (Wayback Machine). Pitch use only.
- Fonts: Gloock and Hanken Grotesk (SIL OFL), self hosted in `fonts/`.
